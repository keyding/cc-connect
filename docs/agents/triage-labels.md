# Triage Labels

| 标准角色 | GitHub 标签 | 含义 |
|---|---|---|
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格充分，可由 Agent 自主处理 |
| ready-for-human | ready-for-human | 需要人工参与实施 |
| wontfix | wontfix | 不予实施 |

技能提到标准角色时，使用对应标签。
实际分诊时检查标签是否存在，按需创建，避免重复命名。
